# color-mix · 点照片，找油画棒配方

纯前端、零外部请求、完全在浏览器本地运行的高尔乐油画棒配色与白纸试色工具。

- **在线访问（GitHub Pages）**：https://fnine59.github.io/color-mix/
- **隐私保护**：照片仅在浏览器内存中解码与取色，不上传服务器、不写入本地存储，无外部字体、CDN 或统计脚本。

## 主要功能

1. **① 放照片，放大镜精准取色**
   - 支持上传照片（手机可拍照或选相册）、拖入图片、粘贴截图或使用内置示例图。
   - **默认独立吸管 + 放大镜**：鼠标悬停或手指按住移动，立即在上方弹出 11 × 11 像素放大镜、准星与实时色值，松手即取中心精确像素并自动推荐配方；也可切换「框选平均」取区域平均色。
   - **照片放大与平移（100%–500%）**：支持工具条缩放/复位、手机双指捏合缩放与平移、桌面放大后平移；双指操作自动取消单指取色预览防止误触。
   - **白纸灯光校正**：在偏黄灯光下可点选照片中的白纸区域进行线性 RGB 白平衡校正，校正选点同样带放大镜预览。
2. **② 照配方试色（高尔乐 237 色）**
   - 在 Web Worker 后台基于 Kubelka–Munk 光谱混合模型（本地打包 MIT 许可的 `spectral.js`）搜索 1～3 支油画棒组合，同时给出「揉匀」与「叠涂」视觉预测。
   - 支持按软硬档次、色系（6 马卡龙 / 7 经典 / 8 莫兰迪 / 中国传统色 / 精选木盒）及个人已拥有颜色筛选。
3. **③ 白纸试一块**
   - 提供油画棒、揉擦白纸、刮刀与白纸吸管四项工具，支持轻/中/重力度、笔刷粗细、20 步撤销与浏览器本地存档。
   - 揉擦与涂抹模拟运行在独立 Web Worker 中，避免多色揉擦冻结交互，并在切页/关闭前同步持久化在途笔画。

> 说明：色表整理自高尔乐官网色号页（237 色），官网色块值与光学混合预测仅作为试色起点，纸张纹理、光线和用力均会影响实物油画棒效果。

## 本地开发与验证

静态网页位于 `site/`，无需构建，通过本地 HTTP 服务即可运行（Web Worker 与 `fetch` 需要 HTTP/HTTPS 环境，请勿直接双击打开 HTML）：

```bash
python3 -m http.server --bind 127.0.0.1 --directory site
```

运行自动化测试与静态安全审计（需 Node 22+）：

```bash
npm ci
npm test
bash scripts/check-palette-static.sh
```

推送到 `main` 分支后，`.github/workflows/deploy-pages.yml` 会自动将 `site/` 部署到 GitHub Pages。
